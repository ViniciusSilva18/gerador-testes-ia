## ✨ Funcionalidades
- 🤖 Geração automática com Gemini AI
- ✅ Suporta Jest, Vitest, Mocha, Pytest
- 📝 JavaScript, TypeScript e Python
- 🧠 Inclui edge cases, mocks e casos de erro

## 🛠️ Setup
```bash
npm install && cp .env.example .env
npm run dev  # http://localhost:3000
```
